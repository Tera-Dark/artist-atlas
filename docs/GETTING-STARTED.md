# 使用说明

在线图鉴：<https://tera-dark.github.io/artist-atlas/>

开发、数据结构、归档流程与运维请看仓库根目录的 `README.md`；这里只讲怎么用。

## 浏览

- 搜索支持画师名称、别名、风格标签和备注，空格与下划线可以混用。
- 可以只看收藏，也可以按最近收录、名称、评分等排序。
- 卡片左右箭头、圆点、键盘 ←/→ 或手机左右滑动切换该画师的三张作品。
- 工具栏「列数」可切每行 2 / 3 / 4 张，默认 3；窗口变窄会自动减少列数，窄屏隐藏该控件。
- 卡片会显示 Danbooru 作品总数与常用别名：总数越大，通常说明该风格在模型里越稳定。
- 点作品图打开大图弹窗：适应 / 100% / 200% 缩放、拖动查看、方向键换图；弹窗里还有「原帖」入口。按住 Ctrl/Cmd 或中键点击则直接打开 Danbooru。
- 点「Danbooru 主页」打开该画师的 Artist 条目。
- 主题默认跟随系统，也可以手动切换；收藏、主题、列数保存在本机浏览器。

## NAI5 画师串

在卡片点「加入组合」，再点页眉的「NAI5 画师串」，可以调整顺序、标签强弱并复制。实际识别效果以 NovelAI 输入框的标签提示为准。组合只存在当前页面会话，刷新后不保证保留。

## 管理图鉴

只有新增、编辑、删除正式画师时才需要 GitHub Token。

1. 打开 <https://github.com/settings/personal-access-tokens/new> 创建 Fine-grained Token。
2. 只选择 `Tera-Dark/artist-atlas` 仓库。
3. Repository permissions 只给 `Contents: Read and write`。
4. 回到图鉴点「管理图鉴」，粘贴 Token 连接仓库。

Token 只存在当前标签页的 sessionStorage，关掉标签页即失效。不要把 Token 发给任何人，也不要截图或提交到仓库。

新增画师流程：

1. 在管理窗口搜索 Danbooru 画师名或 artist tag。
2. 核对返回条目的名称、别名与状态，确认不是同名他人；`is_banned` / `is_deleted` 的条目不收。
3. 填写图鉴显示名、分类、标签、评分、备注。
4. 保存后会在仓库产生一次提交，Pages 部署完成后公开图鉴自动更新。

保存前请确认作者允许作品被重新保存、转换并公开展示。

## 作品更新

GitHub Actions → **Sync Authorized Artist Artwork** → Run workflow，会按当前 score 重新为所有画师选片。改动 `data/artists.json` 或归档脚本时也会自动运行；此外每周一 UTC 03:17 定时复查。

## 常见问题

**作品没有显示？** 先看最新 Pages 部署是否成功，再确认 `data/artworks.json` 的 `display_url` 对应文件真实存在。预览图不是主图来源。

**保存后页面没变？** 等 Actions 跑完并部署完成，再强制刷新；管理界面写入的是仓库文件，不会即时改本地页面。

**想加更多画师？** 先确认再托管许可，再把记录写进 `data/artists.json`，剩下的交给归档工作流。

**为什么只有 3 张？** 每张卡片固定三张：按 score 选出的、互不为差分的作品，避免三张都是同一张画的微调版本。

本仓库不保存任何账号凭证、Cookie 或采集数据；本地工具的数据请留在本机。
